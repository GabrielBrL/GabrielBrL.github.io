Política de Privacidade

Última atualização: 21 de setembro de 2026

Esta política explica como o projeto "Olha Esse Carro Pô!" lida com dados ao usar APIs de terceiros (TikTok Content Posting API, YouTube Data API) para publicar seu próprio conteúdo.

1. Quem opera este projeto

Este é um projeto pessoal, operado por uma única pessoa física, sem equipe, anunciantes ou parceiros com acesso aos dados descritos abaixo.

2. Quais dados são acessados

Ao autorizar a integração via OAuth, o projeto acessa apenas:

  • Informações básicas de perfil público (nome de exibição, avatar) — usadas apenas para confirmar qual conta está autorizada;
  • Permissão para publicar vídeo diretamente na própria conta autorizada (escopo video.publish do TikTok / upload de vídeo da YouTube Data API).

Não acessamos mensagens privadas, lista de seguidores, dados de pagamento ou qualquer informação além do necessário para publicar um vídeo já pronto.

3. Onde os dados ficam armazenados

Os tokens de acesso OAuth (necessários para publicar sem exigir login manual a cada vídeo) ficam armazenados localmente, em um computador de uso pessoal do operador do projeto — nunca em um servidor de terceiros, nuvem pública ou banco de dados compartilhado.

4. Compartilhamento de dados

Nenhum dado obtido via essas integrações é vendido, compartilhado ou usado para fins de publicidade. O único uso é a publicação automática de vídeos já produzidos na própria conta do criador do projeto.

5. Revogação de acesso

A qualquer momento, o titular da conta pode revogar o acesso do aplicativo diretamente nas configurações do TikTok ou do Google/YouTube, o que invalida imediatamente os tokens armazenados.

6. Contato

Dúvidas sobre esta política podem ser enviadas pelos canais oficiais do projeto, listados na página inicial.
